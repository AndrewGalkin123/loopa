07 / Algorithm Cards

The catalog primitive

01 / sorting sort

Bubble Sort — simple

Jednoduchý algoritmus třídění. Ideální pro pochopení principů porovnání a výměn sousedních prvků.

O(n²) beginner
02 / sorting fast

Quicksort — divide

Rozděl a panuj. Volí pivot a rekurzivně třídí dvě poloviny. Mistr v praxi, choulostivý v nejhorším případě.

O(n log n) intermediate
03 / graph-traversal bfs

Breadth-First — ripples

Prochází graf vrstvu po vrstvě jako vlna na hladině. Najde nejkratší cestu v neváženém grafu.

O(V + E) intermediate
04 / shortest-path path

Dijkstra — greedy

Najde nejkratší cestu z jednoho zdroje ve váženém grafu s nezápornými hranami. Hladová strategie.

O((V+E) log V) advanced
05 / search-sorted bin

Binary Search — halve

Vyhledávání v seřazeném poli. V každém kroku zahodí polovinu prostoru. Logaritmické.

O(log n) beginner
06 / optimization dp

Knapsack — pack

Klasický problém dynamického programování. Maximalizuj hodnotu při omezené kapacitě.

O(nW) advanced

2  const n = arr.length;
3  for (let i = 0; i < n - 1; i++) {
4    for (let j = 0; j < n - i - 1; j++) {
5      if (arr[j] > arr[j + 1]) {  // step 07

Proč se bubble sort nazývá "bubble"?
Větší prvky postupně „probublávají" ke konci pole — v každém průchodu se největší zbývající hodnota usadí na své finální místo, podobně jako vzduchová bublina stoupající k hladině.
A nejhorší případ?
O(n²) — když je vstup seřazen sestupně. Tehdy provede n(n−1)/2 porovnání a stejný počet výměn.
